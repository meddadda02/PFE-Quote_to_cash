System Architecture

// QCP — 3-Pass Discount Architecture

// PASS 1 — Analyse lines (bundle count, device count, combo flags)
lines.forEach(function(line) {
  if (family === 'Bundles' && !bundleCodes[code]) bundleCount++;
  if (family === 'Devices') deviceCount += qty;
  if (code === 'MOB-Bun') hasMobile = true;
  if (code === 'BND-TV-HOME') hasHome = true;
});

// PASS 2 — Calculate line discounts (20% cap, exempt codes)
lines.forEach(function(line, idx) {
  line.record['SBQQ__AdditionalDiscountAmount__c'] = null; // FIX: reset first
  line.record['SBQQ__AdditionalDiscount__c'] = null;
  if (!isExempt && base > 0) {
    var maxLineDisc = base * 0.2; // 20% hard cap
    if (lineDisc > maxLineDisc) lineDisc = maxLineDisc;
  }
});

// PASS 3 — Distribute global discount proportionally
lineShare = (ld.net / totalNet) * globalDiscount;
line.record['SBQQ__NetPrice__c'] = Math.max(ld.net - lineShare, 0);

QCP Calculation Sequence

Pass Action Output
Pre-Pass Reset SBQQ__AdditionalDiscountAmount__c, SBQQ__AdditionalDiscount__c, SBQQ__SpecialPrice__c = null Clean state — no poisoned values from Price Rules
Pass 1 Loop all lines → count bundles, devices, detect Mobile/Home/Fiber flags bundleCount, deviceCount, hasMobile, hasHome, hasFiber
Global Calc Query Account → compute Employee/Student/Loyalty/New/Ramadan amounts → convert to local currency via toLocal() globalDiscount, globalLabel
Pass 2 Per-line: apply Price Rule discounts, free products, bundle combo %, device volume → cap at 20% lineDisc, net per line, totalNet
Pass 3 Distribute globalDiscount proportionally: lineShare = (net/totalNet) × globalDiscount → enforce 20% total cap SBQQ__NetPrice__c, SBQQ__CustomerPrice__c, Discount_Breakdown__c

Key Design Decisions

Decision Reason
Feature Min/Max over Not Equal Not Equal evaluates per line → false positives. Min/Max enforces inside configurator scope reliably.
Summary Variables over Not Equal in Price Rules SVs use Count > 0 — unambiguous and reliable.
20% discount cap Protects margin while distributing global discounts proportionally across all lines.
Custom Script over Static Resource for QCP Newer CPQ versions require SBQQ__CustomScript__c. Static Resources produce "Assertion Failed" error.
Before Save Flow for currency Fires at quote creation before any product interaction. After Save would be too late.
Custom Metadata for country-currency mapping Adding a new country requires one metadata record — no code, no deployment.
Bundled=❌ on HW-WIFI-BOOST Bundled=✅ makes Price Rules unable to override price. Booster needs Price Rule to go to 0.
Hybrid CPQ + Revenue Cloud Full RLM migration = 12+ months risk. CPQ handles quoting, Revenue Cloud handles billing post-signature.
Reset AdditionalDiscount in QCP Pass 2 Prevents stale Price Rule values (e.g. 760%) from poisoning QCP calculation.
